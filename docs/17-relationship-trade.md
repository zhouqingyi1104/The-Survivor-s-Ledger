# 人情影响交易

2026-10-24。先规划、后实现。本阶段承接运行时导演的人物往来，把人情变为玩家能主动使用的交易规则；危机时钟、独立 NPC 行动仍是下一阶段。

## 玩家可见结果与范围

宅院的「劫余录」新增「纸鹤往来」入口，灾后第 2 日起每天 08:00–18:00 可在家联系阿宁、老周、过路客。每人每天一份有限报价，选择现货、凭情取货、赊欠、支援或婉拒之一。报价展示交出、得到、原因、后果和期限；欠账、待收回礼与历史随存档和生死簿恢复。断网、关闭 AI、每日局均能使用本地交易规则，不依赖临时生成。

不修改此前已经展示的 AI 事件价格，不让 AI 临时创造欠账或已成交的交易。动态导演读取真实交易背景继续提前策划，既有承诺照常兑现。

## 人情与选择

- 每人分别记录信任（-5..5）、欠你的人情（0..3）、未化解的失约（0..3）以及累计失约次数。信任决定粮价与赊欠资格，人情可兑换一次现货，失约抬高价格并阻止赊欠。
- 原有导演关系只在首次建立交易账本时折算信任；此后真实动态选项的关系变化、邻居求药的给药/拒绝/留药/超时/药账处置直接留下可解释的变动。旧卷不凭空补造借债或失约。
- 现货：支付报价、立即收货，信任 +1；高信任有优惠，低信任或失约有加价。
- 凭情取货：消耗 1 份人情，领取当日同一批货，不再额外赚信任。
- 赊欠：有足够信任且无未化解失约时，先收货，承诺第 2 日后的 18:00 前按固定物资还债。全局最多一笔未清借债，禁止借新还旧；以后改价不改变已签欠账。
- 互助：现在交出明确的物资，次日收到固定回礼，并获得信任与人情。以送材料、送药草等可执行物资互助起步，不把修屋、护送等尚无行动系统的文案当作已经完成。
- 婉拒：不扣物资、不凭空惩罚信任，但放弃该人当天全部报价，次日可再联系。
- 还债：可提前还；过期不自动扣库存，记一次失约，降低信任并加价。之后仍能清偿固定欠账，但失约需要另付补偿才能化解，累计记录保留。
- 补偿：清偿欠账后才能以明确物资补救一次未化解失约，恢复部分信任；不能免费反复道歉刷信用。

三位联系人的现货、互助物资不同。有限日报价和全局借债上限约束资源流，不在本阶段实现独立 NPC 库存与生存模拟。

## 实现契约与分工

- `scripts/core/social_trade.gd`：无网络的核心，依赖 State/Inv/Past 等基础模块，不依赖 Director/Post/Neighbor，避免循环。持久字段 `run.trade`，版本 14 迁移仅补空账本；旧快照同步迁移。
- 核心接口：`state(run)`、`contact(run, actor)`、`quote(run, actor)`、`options(run, actor)`、`act(run, actor, action, quote_id)`、`poll(run)`、`influence(run, actor, delta, source)`、`observe_neighbor(run, choice)`、`context(run)`。`act` 成功返回空字符串，否则返回阻止原因；`last_result` 保存此次结果。每个选项含 `id/text/hint/block`，报价含 `id/actor/day/req/give/reason`；有欠账/回礼的细节由 options 和 context 提供。
- 报价的物资在当天冻结，令牌包含联系人、游戏日与交易版本；成功动作会使旧按钮失效。资源、地点、时间、已有事件、睡眠、忙碌、战斗与交互令牌均由核心再次校验。
- `poll` 无需事件窗口即可结算到期回礼及违约，返回本次新发生事实的文字，重复调用不重复发奖/处罚。Post 在推进时间前后调用，并通过 Director.note_choice 使旧规划失效。
- UI 通过 Post 的交易入口统一执行核心动作、更新导演历史、存档和刷新；交易详情使用可滚动窗口。日夜或不在家时显示明确原因。
- Director 的快照增加可选 `state.trade`，包含三位人物的信任/人情/失约、当日机会、未结债务和回礼；桥接器严格检查字段与数量，不扩大 AI 输出权限。新事实进入历史，AI 不能捏造成交。
- 实现与验证按功能提交：交易核心及规则/迁移测试；玩家入口及窗口交互测试；AI 上下文契约及本地模拟测试。规划独立提交，最终文档按实测回填。

## 验收与对抗审查

1. 同一局面不同信任/失约得到不同价格和赊欠资格，并显示原因；邻居真实选择、导演关系能影响后续交易。
2. 现货、人情、赊欠、互助、拒绝、还债、补偿分别改变库存、机会、关系或固定承诺；所有选项都有可观察后果。
3. 双击、旧令牌、同日重开、缺资源、夜间、离家、忙碌和事件冲突不重复成交、不扣错物资；婉拒后不能重新打开同日机会。
4. 回礼在关闭 AI、睡眠、快进跨日时仍兑现且仅一次；到期当天 18:00 触发违约且仅一次，玩家可在期限前主动清偿。
5. 不能同时向多人赊欠；欠账与回礼不因改价/重规划撤销；清偿与补偿互不混淆，补救不能抹掉历史。
6. JSON 存读档、旧版本与快照升级、翻回昨日都恢复一致事实；每日局不引入跨轮回人情优势。
7. 窗口中实际点击入口、选择、结果、债务与下一日报价；1280×720 内内容可滚动、按钮不越界，存档和 Memory.md 使用隔离路径。
8. AI 契约只用模拟 provider，确认收到真实交易状态、非法状态提前拒绝，保留旧快照兼容；本轮真实 ARK 调用 NOT RUN，未经另行授权不消耗套餐。
