# 《劫余录》内容路线图

2026-11-20 核对，玩法源码基线 `92246ac`，项目版本 `0.10.0`。本页列出一局能玩到什么，以及每个里程碑仍缺哪类证据。近期开发顺序、试玩门槛与难度数据见[优化路线图](37-optimization-roadmap.md)。

## 一局的内容与验收进度

| 里程碑 | 玩家现在能做什么 | 还要验证什么 |
|---|---|---|
| M1 前七日的取舍 | 接受或拒绝隔墙求药，到药铺完成专项目标。送药、自用或超时会改变邻人的去向、回礼和后续关系。规则与窗口已有定向记录。[邻居求药](11-neighbor-medicine.md) | 首次游玩的玩家能否看懂期限，能否把后果与自己的选择联系起来。 |
| M2 不同生存策略 | 同院的人分工，加工燃料、干粮、药散，跟三户纸鹤往来。守夜可在院门用破甲钩防铜甲、在窗前用绳阵防尸海。首版已有规则、接入和窗口记录。[同院的人](15-companions.md) · [加工](16-craft-tradeoffs.md) · [交易](17-relationship-trade.md) · [守具配置](../data/devices.json) | 不同打法能否持续二十日，工作分配有没有减少重复操作。 |
| M3 二十日主线 | 从道士线索到义庄、青云观，本世取证和施工能改变后续尸潮。可达坚守、撤离、破阵三种结局。三条路线有规则与窗口记录。[主线与结局](20-mainline-endings.md) | 首次通关的玩家能否发现替代路线，并理解自己达成结局的原因。 |
| M4 跨轮回变化 | 四身份八种专法、15 项开局筹备、前世记忆，以及旧诺、失约、救助三类轮回调查都已接入。本世仍需重新取证。[前世记忆](14-past-lives.md) · [身份](21-identity-paths.md) · [开局](22-variable-openings.md) · [轮回调查](23-cycle-inquiry.md) | 连玩两世的真实节奏、第二世出现的选择能否被玩家发现。 |
| M5 试玩与分发 | 可快速开局、改键和显示设置、看今日要务和差事、复盘死因与结局、导入导出 `.jyz` 存档、在游戏内填写并导出报告。已有独立 Windows exe + PCK。[设置](24-input-and-display-settings.md) · [存档](32-save-pack.md) · [差事](36-day-agenda.md) · [试玩反馈](45-playtest-feedback.md) · [独立程序](50-windows-release.md) | A4 真人报告、整局节奏、长期平衡、独立机器与正式发行仍待验收。 |

## 横跨里程碑的玩法

- **外出搜寻。** 八处地点已有不同的现场行动、线索和机关。玩家现场搜寻、选择携带物资、权衡风险后返程。米铺、药铺和义庄已有实际窗口路线记录。途中遇事会保留余下路程，未完成的普通翻找不会提前获物。[地点行动](../scripts/core/site_journey.gd) · [线索机关](../scripts/core/expedition.gd) · [外出验证](51-offline-events.md) · [中断与返程](53-interrupted-field-time.md)
- **宅院与街坊。** 营造专项 C0–C6 已接入四向街景和灾后氛围、附加与核心家具挪位、装修、东侧扩建、可进入的地窖与阁楼，以及西邻老周的敲门、修屋、换物和拜访。C5 首批窗口验证通过。11 月 14 日复测时，原版本也出现阁楼施工未完成、入口不能用鼠标点取两处失败。工作台仍有入口，场景拾取待复验。任意家具布局、所有战斗镜头和低配机仍缺覆盖。宅院 C7 以后暂停。[宅院营造专项](31-courtyard-construction.md) · [阁楼复测](58-dialogs-split-house.md)
- **离线剧情与可选导演。** 离线事件表共 72 条，其中 60 条进入随机池。每天 08:00 的调度优先处理已有剧情，符合条件时由随机池补位。危机可调查、干预。三名邻人会依库存和关系行动。开发机可配置异步三日导演，Windows 试玩包以离线内容为基准。[危机](18-crisis-clocks.md) · [邻人自主行动](19-npc-autonomy.md) · [动态导演](13-dynamic-director.md) · [离线调度](51-offline-events.md)
- **复玩与挑战。** 默认二十日之外，可自选誓约、凭仗与了愿，尝试无尽、守到死、每日一局及记分板。现有目标、玩法说明、死因账本和跨日回溯均可在局内使用。[挑战模式](09-challenge-mode-design.md) · [存档安全](25-save-safety.md) · [死因复盘](26-death-recap.md) · [今日要务](33-goal-brief.md) · [玩法说明](34-manual.md)

## 下一步与候选内容

**先回收同一来源版本的真人试玩报告。** 当前有构建来源记录的离线试玩包为 `2bca5ee`。随后四批弹窗拆分已进入源码，最近一批是 `92246ac`。收集反馈时需记下玩家实际使用的包版本。A4 的人数、记录项和 A5 的排序方法见[优化路线图](37-optimization-roadmap.md)。

有了反馈，再判断哪一段最影响体验。白天差事是否重复、寻常年景是否适合第一次游玩、死因复盘是否看得懂，均需玩家回答。扩展候选包括图鉴与成就、更深的地点目标、食物保质期与自由烹饪、交易与求援、多存档槽选择。当前已有存档文件搬运与导入前留档。原版对照列出的缺口属于当时的比较基线。[对照分析](07-survival-log-features.md) · [存档搬运范围](32-save-pack.md)

内容验收继续关注三件事。选择应改变资源、期限、关系、可用行动或后续事件。相关后果应能从提示和日志追溯。接受、拒绝、超时与探索失败都要有收尾。在线提案需经本地规则校验，已承诺的后果在离线时仍可兑现。
