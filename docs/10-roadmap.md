# 《劫余录》内容路线图

更新：2026-10-24。当前实现以代码为准；旧版本设计与数值记录保留，不把历史方案当现状。

## 目标与现状

从「撑过二十天」扩展为「活下来，并决定这座城的命运」。已有采购、经营、夜战、轮回、难度、挑战自选和劫满后无尽；目前探索流程相似、人物关系短、残卷尚未贯通可推进主线。

| 阶段 | 内容 | 验收重点 | 状态 |
|---|---|---|---|

## 当前优先项：运行时动态世情

已实现 [13-dynamic-director.md](13-dynamic-director.md) 的首版滚动三天导演：游玩中使用 ARK Agent Plan、low reasoning，根据库存、人情、已发生选择和承诺异步规划；选择后更新未来，已许下的回报按约兑现。点击不等待网络；生成失败或快进超过准备速度时仍可继续原有内容。

真实 ARK 返回的 3 场事件、9 个选项已经离线回放到规则与窗口界面；慢请求行走、存读档、过期响应、重复发奖和请求去重验证通过。独立 NPC 目标、危机时钟、动态地图任务仍在后续计划，不把文字生成当作这些系统已完成。

下一步按玩法价值推进：先让人情往来影响交易条件，再加入玩家能提前得知和应对的危机时钟，最后让 NPC 围绕资源与去留自行行动。每层都要能解释「此前做了什么，为什么今天发生这件事」。详细边界与验收见文档 13。

本批交付：7 个决策节点、15 个选项；任务从第 2 日求药到义庄药账处置，含赠药、拒绝、自留、超时、修屋/粮柴回礼、有偿换路、留宅、公开/封存证据。规则与 UI 自动验证已通过，尚未玩家验收。ARK 实际调用与采用范围见 [12-neighbor-ai-review.md](12-neighbor-ai-review.md)。

## 内容验收原则

- 选项必须改变资源、时限、关系、可用行动或后续事件之一；文案换词不算新分支。
- 主要后果有可读的成本提示，并在后续任务日志中回指选择。
- 接受、拒绝、超时、自用、探索失败都有收尾，不能随机漏掉主线。
- 新地图要有独有目标；延长天数、增加难度或事件数量不能代替新体验。
- AI 在规则限定的预算内提出事件，不执行代码、不直接改存档、不持有玩家凭据；当前事件提前准备好，断网不阻塞玩法，已承诺的后果照常兑现。
