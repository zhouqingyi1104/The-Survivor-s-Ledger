# 《劫余录》内容路线图

2026-11-29 更新，玩法候选版本 `0.13.1`。默认剧情为三天备荒、灾后一百天。本版调整主角在桥市、宅院与遗迹的起步、转身及收脚。各里程碑的玩家目标见下表，试玩包和下一批验收见[优化路线图](37-optimization-roadmap.md)。

## 一局的内容与验收进度

| 里程碑 | 玩家现在能做什么 | 还要验证什么 |
|---|---|---|
| M1 前七日的取舍 | 接受或拒绝隔墙求药，到药铺完成专项目标。送药、自用或超时会改变邻人的去向、回礼和后续关系。规则与窗口已有定向记录。[邻居求药](11-neighbor-medicine.md) | 首次游玩的玩家能否看懂期限，能否把后果与自己的选择联系起来。 |
| M2 不同生存策略 | 同院的人分工，加工燃料、干粮、药散，跟三户纸鹤往来。守夜可在院门用破甲钩防铜甲、在窗前用绳阵防尸海。首版已有规则、接入和窗口记录。[同院的人](15-companions.md) · [加工](16-craft-tradeoffs.md) · [交易](17-relationship-trade.md) · [守具配置](../data/devices.json) | 不同打法能否持续二十日，工作分配有没有减少重复操作。 |
| M3 首卷的三条路 | 查访义庄和青云观，可选坚守、撤离或破阵。百日剧情把首卷去路带进后四幕；自选二十日短篇在此结案。[首卷调查](20-mainline-endings.md) | 首次游玩的玩家能否理解自己为何走上这条路。 |
| M6 百日街坊 | 五幕从水井、摆渡、医馆写到瓦窑和重开街市。九名街坊轮流到院里，有事能当面谈，夜里也能回信。早先的答复有时能换来一门长期差事。第一百日写下街坊的去处，守过当夜收卷。[百日玩法](player-guide.md#百日街坊) | 用同一存档观察玩家在哪一幕想继续、在哪一幕觉得重复，再按实际游玩时长调整事件间距。 |
| M4 跨轮回变化 | 四身份八种专法、15 项开局筹备、前世记忆，以及旧诺、失约、救助三类轮回调查都已接入。本世仍需重新取证。[前世记忆](14-past-lives.md) · [身份](21-identity-paths.md) · [开局](22-variable-openings.md) · [轮回调查](23-cycle-inquiry.md) | 连玩两世的真实节奏、第二世出现的选择能否被玩家发现。 |
| M5 试玩与分发 | 可快速开局、调整显示和键位、看今日要务与差事、复盘死因与结局、搬运 `.jyz` 存档。宅院操作提示会跟随改键，院门战中可点印翻阅劫余录。独立 Windows 包可在本机导出带构建提交的试玩报告。[设置](24-input-and-display-settings.md) · [存档](32-save-pack.md) · [差事](36-day-agenda.md) · [试玩反馈](45-playtest-feedback.md) | A4 真人报告、整局节奏、长期平衡、独立机器与正式发行仍待验收。 |

## 横跨里程碑的玩法

- **街坊同行。** 增加 15 宗可选调查，其中 13 宗从第 41–95 日陆续开启，3 宗须在前案留下约定。第 41–100 日共有 28 天会开启新主信或公开支线，隐藏线全开时为 31 天。到遗迹认实物、带回院里合办，能改变下一位带路人、后案结法和公灶分给各家的粮水。下一轮真人试玩关注玩家能否记起触发后案的那次选择，以及哪些天仍然太空。[同行玩法](player-guide.md#街坊同行)

- **备劫三日。** 买完东西仍有两桩可选的活：帮米行卸粮换一张炊饼，或回院劈柴存下两捆燃料。两桩活各占一个时辰，所得直接进家中存货，可带到尸劫之后。愿意提前歇息也能照常过日。[三日备荒](player-guide.md#三日备荒)
- **米行旧事「燕尾担」。** 卸粮后可以翻看短扁担，顺着纸条到书肆找人。在那里能学挑担，长五点气血上限，也能学辨认旧记号，得十点搜寻经验。本世只能选一门。灾后重访废弃米行，两种学法各能看懂残账里的一处细节。[起手提示](player-guide.md#三日备荒)
- **外出搜寻。** 八处地点已有不同的现场行动、线索和机关。玩家现场搜寻、选择携带物资、权衡风险后返程。米铺、药铺和义庄已有实际窗口路线记录。途中遇事会保留余下路程，未完成的普通翻找不会提前获物。[地点行动](../scripts/core/site_journey.gd) · [线索机关](../scripts/core/expedition.gd) · [外出验证](51-offline-events.md) · [中断与返程](53-interrupted-field-time.md)
- **宅院与街坊。** 从桥头侧门看进去，石阶通向正厅，灶间围出井院，另一侧是赏梅台。灾后宅院的西卧房前挑、中厅后退、东书斋折出三面，西廊连通卧房与灶间。阁楼梯口和朝外的窗龛各自成间。床沿垂下棉被，书斋铺编席，院里能看见井边湿石和瓦口的叠影。营造专项 C0–C6 已接入四向街景、家具挪位、装修、东侧扩建、地窖与阁楼，还能去西邻老周家敲门、修屋和换物。下一次试玩观察新玩家能否凭屋形找到床与书案、从西廊走到灶间。任意家具布局、所有战斗镜头和低配机仍缺覆盖。[宅院营造专项](31-courtyard-construction.md) · [阁楼复测](58-dialogs-split-house.md#11月20日阁楼复测)
- **地窖储物与阁楼起居。** 下楼后，搬运车和垫仓板在梯口，分拣台与三格干货柜面向过道。点击柜身，人物会走近查看实存物资。上楼后，换洗短褂和脸盆靠窗，针线桌挪到屋内。点帐床可走到床边小憩，夜间可依守夜规则就寝。旧卷在同处摆过家具时优先展示玩家原有布置。
- **全场景模型。** 两套主角服装有不同的刺绣与织纹，街坊的衣领、长衫与裤脚随原骨架行动。桥市换上石拱桥与成排木作铺面，八处遗迹有各自的建筑与搜寻实物。官仓粮车可辨车轮、辐条和车上叠袋，药铺的药罐和处方放在木托盘上。下一轮试玩观察玩家能否从轮廓认出目标，以及夜间的提示圈是否易读。
- **二维美术。** 从启动画面和标题进入桥市，可按店铺图记找地点，交易与外出搜寻时能按同一套物资插画认货。回宅可见厅中双面柿树屏风、四时花灯、靛蓝鱼纹被，门外可辨春联和镇符。设置、日志与事件共用线订书衣。下次真人试玩观察小字号下能否认出图记，以及夜间弹窗能否读清。[美术来源](03-art-assets.md)
- **离线剧情与可选导演。** 离线事件表共 72 条，其中 60 条进入随机池。每天 08:00 的调度优先处理已有剧情，符合条件时由随机池补位。危机可调查、干预。三名邻人会依库存和关系行动。开发机可配置异步三日导演，Windows 试玩包以离线内容为基准。[危机](18-crisis-clocks.md) · [邻人自主行动](19-npc-autonomy.md) · [动态导演](13-dynamic-director.md) · [离线调度](51-offline-events.md)
- **复玩与挑战。** 百日与二十日短篇均可自选身份、誓约、凭仗与了愿；每日一局和守到死使用各自的挑战日历。现有目标、玩法说明、死因账本和跨日回溯均可在局内使用。[挑战模式](09-challenge-mode-design.md) · [存档安全](25-save-safety.md) · [死因复盘](26-death-recap.md) · [今日要务](33-goal-brief.md) · [玩法说明](34-manual.md)

## 下一步与候选内容

### 本轮内容版本

桥市已有卸粮、劈柴和燕尾担，灾后已有即时烹饪、八处遗迹及三条结局。0.11 在四个阶段加入跨日或跨地点的选择。

| 游玩阶段 | 玩家要做的决定 | 在游戏里怎样验收 |
|---|---|---|
| 备劫三日 · 七号药签 | 逛药铺时主动查一只旧药包。学徒识得封签，其他人可留下等药师。灾后决定自己领药，或把药送给渡口的人。 | 从第一天药铺走到灾后纸鹤；两条结尾各有实物或回信，离开商店、跨日、读档和再点一次都要试。 |
| 灶间 · 共用晒匾 | 把杂粮或萝卜留作今天吃，或先占住晒匾；初晒时收一批应急，还是翻面多等一天。 | 开工扣家中实物；等候期间照常外出、守夜。回厨可见哪天能收，成品可食用，领取后才能再开一匾。 |
| 中盘外出 · 旧运路 | 在现场拿走眼前的物资，或用随身找到的材料留记，下一趟去另一处找寄存物。 | 至少三对具体地点；离开后还能查目的地。半途遇事、背包装满、读档和重访都有明确结果。 |
| 第十二日起 · 巷口留灯 | 花灯油联络被困街坊。隔天收到回音，选择腾出院内住处或资助渡船，也可留着家底过夜。 | 来信前无法提前结算。两条路分别改变宅院或第二十夜的压力，最后在结局读到这一世街坊的去向。 |

这四条线都已接入本地游戏，并走过规则和窗口验收。额外修通了腌菜坛、熏肉架和捕鼠笼的实地操作与清晨收货。「等一刻」若将跨过送药或还账期限，会显示赴约与继续等两个选项。固定种子 9201–9204 用两种打法各跑四局，八局都守过第二十夜。这个结果说明熟练打法能走完流程，真人难度、乐趣与最先感到重复的日子仍待试玩。[上手指南](player-guide.md)

参考时取了三个具体做法。《生存日志》让灾前储备在灾后派上用场；《漫漫长夜》让出门所得与时间、体力彼此制约；《这是我的战争》让照顾他人也消耗你自己可能需要的物资。[《生存日志》](https://store.steampowered.com/app/4164790/?l=schinese) · [《漫漫长夜》](https://store.steampowered.com/app/305620/The_Long_Dark/) · [《这是我的战争》](https://store.steampowered.com/app/282070/This_War_of_Mine/)

**9/10 是玩家对候选版本的整体可玩性评分目标。** 沿用 A4 的同包至少三名独立试玩者，保留每份原分、游戏进度、最想再玩或退出的一刻，含中途停玩的反馈。报告给出有效人数及平均分，空白不计分，同时列出未评分人数。用玩家提到的重复日、看不懂的取舍和功能故障继续改版。自动通关、开发自测、商店同类作品评分都不能代填。[试玩与反馈](37-optimization-roadmap.md)

隐藏故事的试玩观察点是卸粮后有多少人自己翻了扁担、灾后是否认出了同一本账，以及药签两个结尾是否让人想换种身份再玩。

**已接入 · 旧物手记。** 发现燕尾担、七号药签、旧运路或巷口灯之后，可在离场、跨日和续档后翻看自己见过的物件、做过的决定及仍然有效的去向。第一次亲手发现前不显示入口，另一条结尾留待再玩。窗口定向验证已覆盖备劫与灾后入口、旧卷状态和翻页不改变局面。真人试玩将观察隔日回来是否还能续上旧线索。

扩展候选包括图鉴与成就、更深的地点目标、食物保质期与自由烹饪、交易与求援、多存档槽选择。当前已有存档文件搬运与导入前留档。原版对照列出的缺口属于当时的比较基线。[对照分析](07-survival-log-features.md) · [存档搬运范围](32-save-pack.md)

内容验收继续关注三件事。选择应改变资源、期限、关系、可用行动或后续事件。相关后果应能从提示和日志追溯。接受、拒绝、超时与探索失败都要有收尾。在线提案需经本地规则校验，已承诺的后果在离线时仍可兑现。
