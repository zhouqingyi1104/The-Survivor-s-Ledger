## 范围与验收合同

1. 使用内置 imagegen 生成四张透明图集，4×4 等格；每格有安全留白。其余 55 件映射至对应区域，米与铁钉继续使用现有独立 PNG。每一件必须能在实际裁图中辨认，不以映射数量冒充视觉验收。
2. 统一哑光粗糙材质、自然磨损、克制墨线与淡彩；不做高光、发光、背景板、文字贴纸。粮食、种子、药包和书册用物件、颜色和小图案区分，物品名称仍由界面真实文字显示。
3. 新模块只管理存货插画；其它入口与家具继续沿用既有代码图标。未知未来物品保留兜底；对当前 `items.json` 的 57 个 ID 则严格覆盖，禁止漏项或图集区域重复映射。
4. 分类、数量、效果、说明、真实吃喝用药按钮、空库存、客宅限制和 Esc 保持可用。卡片宽度、四列、图片尺寸与滚动范围保持现有合同。
5. 先做资源与区域检查，再以隔离用户目录在真实 1280×720 窗口逐类截图、检查全部插画，并验证筛选、滚动和使用后刷新。发现不清楚、串图、切边或风格偏差时修正资源，不能降低断言。
6. 保留 `art-previews/` 和文案任务的未提交内容；只将本批选定图集、导入设置、消费代码、必要定向测试与文档提交。提交后立即正常推送并核对 SHA，再从该干净提交刷新便携包。

## 实际结果与素材来源

既有米、铁钉来自提交 `8836c3c`，原图不改。其余 55 件由内置 `image_gen.imagegen` 生成，不是第三方素材或人工手绘；未使用 CLI 或付费外部 API，没有脚本像素后处理。最终原 PNG 按字节复制至：

- `assets/ui/inventory/food_atlas.png`：16 件。
- `assets/ui/inventory/supplies_atlas.png`：16 件。
- `assets/ui/inventory/tools_atlas.png`：16 件。
- `assets/ui/inventory/misc_atlas.png`：7 件，余九格不使用。

四图均为 1254×1254 RGBA，`AtlasTexture` 按浮点等格 313.5px 取图。提示词与选定素材 SHA256 保存在 [47-inventory-art-prompts.json](47-inventory-art-prompts.json)。初稿边距不足；一次留白调整令食物/用品出现半透明白底，这两张再提取背景后选用。未选中的原图与其它候选不入库，`art-previews/` 保持不动。

提示词要求的 15% 留白并未在每格完全达到：最终 alpha≥128 实体最小边距为 8.28% / 12.74% / 15.61% / 15.61%。验收依据是实际采样区域无实体碰边、无邻图串入及 72px 窗口效果；不能宣称全图达到 15%。原生透明图预览会显出 alpha=1/255 的 RGB，实际旧纸合成图中没有可见杂点或白底。
