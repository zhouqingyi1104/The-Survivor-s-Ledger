# 《劫余录》玩法完善方案 v0.5

> **状态：已被 `docs/06-night-defense-v0.6.md` 取代其中「守夜方略」一章。** v0.6 把 21:00 的三选一拆成「门 / 窗 / 院墙三面 × 三轮 + 轮间操作 + 三个方针」。本文保留，作为 v0.5 那一步的决策记录与体温 / 尸潮曲线 / 事件 / 功德的依据。

> 依据：`docs/04-gameplay-diagnosis.md` 的实测证据。
> 范围：只动**劫中（post）**的玩法回路；备劫三日、美术、音频不在本轮。
> 版本：Godot 4.7.2 / Windows。数值全部可在 `data/*.json` 与 `scripts/core/*.gd` 顶部常量改。

## 0. 本轮目标

把「白天攒资源 → 夜里被动挨打」改成「**白天攒资源 → 21:00 用资源换守力 → 22:00 结算**」，让守具、符纸、灯油、柴炭第一次变成**看得见的筹码**；同时让第 10 日之后不再是空转。

三条设计原则：

1. **夜里必须有输入**：每夜至少一次决策，且决策要在结算前给出可比较的预测。
2. **压力要能被看见**：所有威胁在 HUD 上给出「预计 vs 需求」，不做黑箱。
3. **失败必须可归因**：死的时候玩家要知道自己缺的是柴、是木料，还是没舍得点符。

## 1. G1 守夜部署（本轮主玩法）

### 规则

- 触发：尸潮夜 **21:00（酉时末）**，时间暂停，弹出「布防」。
- 玩家在三个方略里选一个（互斥）；选完时间继续，22:00 按所选方略结算。
- 没选就卡住不动（`Post.blocked()` 含 `posture_due`）；旧存档 / 异常路径下默认「闭门死守」。

| 方略 | 代价 | 效果 | 设计意图 |
|---|---|---|---|
| 闭门死守 | 无 | 门损 ×0.85；自身武力 ×1.0 | 保底选项，永远可用 |
| 亲自守门 | 精力 −15 | 自身武力 ×1.7；斩尸 +8%；破门伤害 ×0.5；漏怪时功德 +1 | 用「明天的精力」换今夜的活路 |
| 燃符布阵 | 镇尸符 ×3 | 守力 +12；月黑失效 | 把备劫囤的符变成即战力 |

### 结算公式

```
守力 = 守具之和 + 望楼4 + 阿黄3 + 夜行4 + 六丁六甲10 + 方略固定加成
     + 自身武力 × (0.5 + 精力/200) × 方略倍率
     然后：体温 < 15 → ×0.85（手脚冻僵）
           月黑且无灯且非"燃符" → ×0.7

斩尸 = floor(守力 / 每只消耗 × (1 + 斩尸加成))
漏怪 = 来袭数量 − 斩尸
漏怪伤害 = 漏怪 × leak(日)
leak(d) = 6 + floor((d−1)/4)          # 第2夜6 … 第20夜10
门损 = 漏怪伤害 × (1 − 窗占比) × 方略门损系数
窗损 = 漏怪伤害 × 窗占比
破门进院：ceil(漏怪 × 0.5) 只，每只 5 气血 × 方略受伤系数（再乘"无常勿近"减半）
```

### 极值验算（第 20 夜血月，必须能算清）

- 来袭 `58 × 1.2 = 70` 只，每只耗守力 `1.3` → 全歼需要 `70 × 1.3 = 91` 守力。
- **情形 A：守力 40，闭门死守** → 斩 `floor(40/1.3)=30`，漏 40 → 伤害 `40×10=400`。门窗合计 260 → 必破。进院 `ceil(40×0.5)=20` 只 ×5 = **−100 气血**，直接死。
- **情形 B：守力 40，亲自守门** → 进院伤害 ×0.5 = **−50 气血**。气血 80 时剩 30，能活。
- **情形 C：守力 40，燃符布阵（+12）= 52** → 斩 `floor(52/1.3)=40`，漏 30 → 伤害 300，门窗 260 → 仍破；进院 15 只 ×5 = −75。
- **情形 D：守力 70（补了守具），亲自守门** → 斩 `floor(70/1.3×1.08)=58`，漏 12 → 伤害 120，门窗 260 → 不破，只掉耐久。
- 结论：**91 守力是第 20 夜的「全歼线」，70 是「不破门线」，40 是「必破线」**。玩家在 21:00 看到的就是这三个数之间的关系。

### 界面

- 布防弹窗：标题写「第 N 夜 · 布防」，正文写「今夜要来 X 只（词缀）、每漏一只掉 N 点耐久」，三张卡各写「预计守力 / 预计斩 X 只 / 漏 Y 只」，资源不够的卡直接标红原因。
- HUD 左上预警栏加一行：`布防 闭门死守：守力 12.0 / 需 44，漏 22 只`（够则绿，不够则红）。
- 战报标题行补上所选方略。

## 2. G2 体温成为真约束

### 改动

| 项 | 改前 | 改后 |
|---|---|---|
| 白天回暖 | +2.0/小时，**无上限**，必回满 | +2.0/小时，上限 **60**（有地窖 75） |
| 生火回暖 | +2.0/小时，上限 100 | 同，但**一捆柴只能烧半夜**：+1.0/小时，上限 70 |
| 睡眠回血 | 只要饱食水源 >20 就回 | 额外要求 **体温 ≥ 30** |
| 睡眠回精力 | 全额 | 体温 <15 时打 6 折 |
| 低温掉血 | <30 统一 −0.7/小时 | <30 → −0.7；**<15 → −1.4**，另掉心神 |
| 守力 | 不受体温影响 | 体温 <15 → **×0.85**（手脚冻僵） |

### 极值验算（连续不取暖）

寒夜 12 小时（18:00–6:00），寒气 30 → 每小时 −3.0：

| 夜 | 入夜体温 | 天亮体温 | 当夜掉血 |
|---|---|---|---|
| 1 | 60 | 24 | ≈1.4（只在最后 2 小时进 <30 区间） |
| 2 | 60−36+24=48 | 12 | ≈4.2+8.4=12.6 |
| 3 | 36 | 0 | 16.8 |
| 4 | 24 | 0 | 16.8 |

→ 第 2 夜开始掉血，第 3 夜起每晚固定 −16.8，气血 100 的人在连续 5 夜不取暖后必死。这就是「柴炭断供」应有的后果。
→ 有火（2 柴）时 60→84（上限 100），一夜无损；所以火是**维持手段**，不是积累手段。

## 4. G4 中后期事件供给

新增 4 条**可重复**事件（`min_day ≥ 7`，无 `once`），覆盖存粮损耗、夜半叩门、游荡尸群、河面封冻。每条都带「花资源换好处 / 硬扛赌一把」的两难，且都接在已有的效果词汇表上（`items / merit / mood / hp / energy / roll / plague`），没有新增机制。

## 5. G5 功德通胀收敛

求签改为**同日递增**：`实际成本 = 基础成本 + 当日已求支数`。第 2 支 +1，第 3 支 +2。
这是轻度收敛，不是重做；功德的长期盈余问题仍在待办里。

## 6. G6 两处「无解」的补救（属于修 bug，不是加玩法）

诊断时发现两个死结，会让后期变成不可挽回的死亡螺旋：

1. **木料断供 → 门窗永远修不了**。改后：没有木料时，**拆 2 捆柴顶 1 根木料**。
2. **探索只给配方内的产物，废墟里拆不出柴**。改后：每次翻找有 **35%** 概率顺手拆 1 捆柴（背得下才拿）。

## 7. 改前 / 改后对照

| 指标 | 改前 | 改后 | 说明 |
|---|---|---|---|
| 12 局劫满 | 11 | **10** | 变化不大，正常 |
| 平均存活 | 19.9 日 | 19.8 日 | 持平 |
| 死亡分布 | 1 局（第 20 夜） | **2 局，均在第 20 夜破门** | 终局变成真·生死关 |
| 20 日气血 | 82 | 25～77（分布很散） | 过程强度上来 |
| 第 14 夜后体温 | 恒为 0，无后果 | 0～62 波动，持续掉血 | 冷开始咬人 |
| 守力曲线 | 41→21→67（不可读） | 38→23→59（HUD 有预测） | 可读性来自 UI 而非数值 |
| 每夜决策数 | 0 | 1（三选一） | 本轮核心 |
| 偷懒策略 | 4/4 死于第 10–11 日 | 4/4 死于第 10–11 日 | 未回退 |

> 诚实说明：**胜率没有大幅下降**（11/12 → 10/12）。本轮改的是「过程有没有压力、有没有选择」，不是「把游戏做难」。想更硬，改 `waves.json` 的 `count` 和 `defense.gd` 的 `LEAK_STEP_DAYS` 即可。
