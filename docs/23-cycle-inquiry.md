# M4：跨轮回事件与轮回调查

2026-10-24。先规划、后实现。让旧诺、失约和救助成为新世可以查证、重新选择并产生延迟后果的内容；旧债、旧奖励和本世证据不自动继承。

## 玩家闭环与验收条件

出生从已封存真实记录固定最多两名不同人物的旧案，覆盖旧诺、失约、救助三种来源。旧卷只能从仍可核实的实际药物交付、贸易欠约或累计真实失约导入；没有事实的第一世不造案。每人物最新来源保留有界永久索引，详细八世叙述裁切不丢失已确认线索。本世开始后不吸收后来封存的经历。

默认在第3、6日08:00公开玩家残梦。玩家可在「劫余录 → 轮回调查 · 旧诺与今证」主动追查，不必等NPC随机觉醒。残梦属于玩家所知；NPC本人实际觉醒且actor/世次/fact_id精确匹配的碎片，才可作为另一条线索，其他人不能引用。未查证的旧事不等于今世证据。

本批地点明确为宅院查访与核对本世账页，不新增地图专点：

1. 查访本人：30分钟、精力4；工作完成才得到当前线索。
2. 对照今世账页：米1、45分钟、精力5；若本人已真正觉醒对应片段，可选择水1、30分钟、精力5的交叉核对。两路互斥，起工扣料，完成才得到今世证据。
3. 当前实际处境有「急需」与「尚稳」差异，出生独立播种、不改掉落随机计数；只有查证完成才公开，影响后续已明示回礼。AI和未查证界面不能提前知道。
4. 每案公开后第5日18:00截止。起工应检查能否按期完成；恰在截止时完成允许结算。中断保留原阶段、耗材不退，过期有收尾，不能重复领物。
5. 查明后选择一项今世方案，真实扣钱物、耗时，完工后改变信任/人情与后续NPC决定；新约回礼按固定日期兑现一次。旧债、当日报价、已签债据及原回礼不会被改写。

## AI、存档与归档边界

- 本地规则有完整默认排期与全部调查/选择，离线和慢请求仍可继续。沿用线程HTTP、low reasoning、节流和debounce；点击不发起同步模型等待。
- AI只从已提供的未公开候选选择case_id、未来1～3天的合法公开日及审核cue ID。不能新增案件、改来源或私人处境，不能替玩家查证、扣物、发奖或改变公布后的时限。公开后排期冻结。
- AI公开上下文只含本世可用的案况、实际工作与已许回礼；私有来源ID和未查明处境不入快照。NPC知情仍以本人recollections为准。选择与世界进展增加导演revision，过期响应不能倒改案件。
- 存档v20；旧本局和回溯快照设中立已关闭，不从新meta追授案件或补发。每日局API禁用，不带个人旧案、觉醒或规划。
- 合卷真实更新玩家运行时Memory.md，加入调查、未完工、实际选择与已/未兑现回礼作为第七系统；最新一世七系统保留在8000 UTF-16预算内，结构化meta不为缩篇幅裁切。玩家根文件测试隔离，不提交。
