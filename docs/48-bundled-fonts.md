# 内置中文字体（2026-11-05）

状态：首版实现，本地资源 204 检查、窗口 3800 检查 PASS。本文先写范围与合同，再补实际结果；独立无楷体机器/虚拟机、跨平台一致性与玩家验收 NOT RUN，C3 整体验收仍未完成。

## 玩家得到什么

承接优化路线图 C3。离线试玩包随包携带中文字体，纸面与标题仍用楷书，深色正文和 HUD 仍用黑体，时辰表盘和场景招牌也使用同一套内置资源。玩家无需安装楷体、雅黑或联网下载字体。

## 范围与验收合同

1. 从上游官方固定版本或提交取得霞鹜文楷 Regular、Noto Sans SC 可变字体，保留原始字体字节及完整 OFL 许可，记录来源、版本、SHA256 和增加的体积。不安装系统字体，不引入包依赖，不修改 `.env`。
2. 字体统一由一个资源入口提供，替换纸面主题、深色主题、HUD 普通/粗体、时辰表盘、3D Label 招牌的系统字体构造。内置字体禁用系统回退，粗体使用字体自身的字重轴。
3. 保持既有字号、配色、按钮和布局合同；既有存货插画不变。修正本批字体度量直接导致的裁切或不可点击问题，不扩展到界面重设计。
4. 定向检查真实界面字符覆盖、内置字体资源/粗体轴与各入口接入，禁用系统回退时仍能渲染中文、标点、数字、箭头及十二时辰。检查标题、白天/夜间 HUD、存货、设置/反馈和场景招牌的实际 1280×720 截图；交互验证字体变化影响的按钮、滚动与文本输入。
5. 将完整字体许可随包分发。从验证后的干净提交出包，再用实际 exe 验证字体资源、许可、中文字形和启动截图；不能把本机装有楷体时的正常截图当作无楷体机器验收。
6. 保留 `docs/40-copy-round5.md`、`docs/41-copy-review.md`、`art-previews/` 和其它任务内容。只提交本批文件，验证后立即正常推送并核对远端 SHA。

## 未验收边界

本批不调整 B4 数值、B5 白天玩法，也不新增系统。真人试玩、A4/A5、独立无楷体机器/虚拟机、跨平台截图一致性、CI、全量测试与正式发行仍需单列实际证据；本机禁用系统回退只证明字形来自随包字体，不替代实体环境验收。任意玩家输入的罕见字或表情不承诺全部覆盖。

## 实现与素材来源

- `scripts/ui/fonts.gd` 统一提供 `book()`、`body()`、`bold()`：霞鹜文楷 v1.530 原始 Regular 用于纸面、标题、时钟和 3D 招牌，Noto Sans SC 2.004 原始可变字体用于深色正文和 HUD。两份导入设置与运行时都关闭系统回退，不再创建 `SystemFont`。
- 字体从官方固定提交取得，原始二进制与对应上游 Git blob 相同，没有裁字、转格式、系统安装或依赖安装。两字体总计 43,702,072 B（41.678 MiB），各自版本、来源、SHA256 和许可证见 [SOURCES.md](../assets/fonts/SOURCES.md)。
- 两份完整上游 OFL 及字体自身版权声明保存在 `assets/fonts/LICENSES.txt`。两种 Windows 构建模式及干净提交构建均将其复制为 exe 旁的「字体许可.txt」，缺失或为空会停止替换旧包。包内字体能否加载、许可是否齐全及实际体积，在提交后的干净构建单独检查，证据以包内 `构建来源.txt`、本机 `验收记录.txt` 为准。
- 暂停按钮由不在主字体中的 `❚❚` 改为主字体原生覆盖的 `Ⅱ`，仍是双竖线、操作不变，18px 下宽度约 17.5→18px。曾试用的 Symbols2 抬高全部行高（18px 时 22→32、84px 时 100→143），因此移出最终资源；没有用排除缺字的方式放宽全源码扫描。
- Godot 4.7.2 实测忽略字重轴字符串别名 `wght`，400/700 会落回默认 100 并共用 RID；现使用数值 OpenType tag `0x77676874`，实际 TextServer 变体坐标分别是 400/700。测试检查引擎坐标和不同 RID，而不只检查配置字典。对应上游问题：[godot#123541](https://github.com/godotengine/godot/issues/123541)。
