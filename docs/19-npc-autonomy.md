# NPC 自主行动与受约束对话

2026-10-24。先规划再开发，承接人情交易与危机时钟。验收以玩家能够观察、介入并看到实际后果为准。

## 本批可玩的循环

阿宁、木料场老周、过路客各有独立的周转物资（米粮及擅长货物），不是玩家库存，也不是已经留给现货报价、赊欠和回礼的契约货盘。第2日起每天08:00各作一次决定、16:00执行；意图、资源、原因、期限提前公开。每天米粮消耗1；不欠玩家的粮，不暗扣玩家库存。旧存档从当前日之后开始，不追补过去。

本地规则按顺序选择：米粮或擅长货物不足先外出筹措；公开且相关的危机使其备货自保；当前低信任/未化解失约或本人已觉醒后被疏远时收紧往来；信任、人情或本人已回应的旧世记忆足够时主动送物；其余恢复周转。阿宁擅长艾草、老周木料、过路客柴。危机只读取公开阶段，不读隐藏真假；前世只读取本人已经觉醒的片段及回应，不读 inherited/schedule/Memory 全文。

| 决定 | 16:00的实际结果 | 后续玩家选择 |
|---|---|---|
| 筹措 | 粮少时觅粮最多+2，否则耗米1补擅长货物最多2；支援后最多3；按20的容量显示实际增量，满库整理不耗米 | 后续自主行动由新库存决定 |
| 备货 | 耗擅长货物1保护自身周转；新报价加米1，得到支援则不加 | 危机外另有自保取舍，旧报价不改 |
| 收紧 | 暂停新报价赊欠并加米1；得到支援则恢复 | 玩家可先改善信任，也可接受更严条件 |
| 回报 | 从本人周转物资扣擅长货物1，16:00送到玩家家中；接受支援后扣2送2 | 人情改变真实物资，不凭空发奖 |

每个公开决定都可选择一次：
- 送物支援：缺粮交米2，否则交该角色擅长物资1；实际加入NPC周转库存，立即信任+1、人情+1（上限3），16:00改善上述结果。人情满、库存满、交付后筹措目标已无增长空间均拒绝且不扣物资；容量只剩1时显示实际+1，不承诺固定+3。已经签下的代价不随重规划变化。
- 凭情改托：有真实人情1和对方擅长物资1时可改托；立即消耗人情并预留物资，16:00按约送货，原计划让位。不能把同一物资用于原回报或重复收取；不挪用旧契约。
- 由他安排：零成本、无失约处罚，关闭本次介入；到点照原计划执行。没有回应也到点执行，不暂停等玩家。

新报价只采样执行后的 price_add/credit_allowed 与本地原因并冻结。之后NPC改变主意不得回改当日报价、已借物资和已约回礼。受益、筹措、耗用均记账，有界库存，重复poll/存读档不能重发。后续危机、交易、觉醒和玩家介入进入未来日决策与AI公开事实。

## 接口及职责

- 新增 core/npc_autonomy.gd：state/poll/view/options/act/context/market_effect。只依赖 State/Inv/Data/Past/Crisis，直接原子更新已有trade账本人情/信任，避免Trade循环依赖。run.npcs持久保存schema/revision/next_day/actors/history；每人保存stock/plan/policy/last_result。存档v16，当前局和回溯快照迁移。
- plan具有id/day/due_t/mode/focus/reason_codes/reason/response/req/reserved/status；view提供本地title/goal/reason/memory/stock/plan/token/last_result，UI不从私有字段拼事实。令牌绑定本世/角色/计划/revision；到点、跨世、旧按钮拒绝且不扣物资。
- Post统一顺序：危机 → NPC → 已签交易回礼 →导演；只有实际新事实使规划失效。后台NPC新事实重规划未来，但保留今天尚未展示的已准备经济机会，强制本地事实文案；否则每日08:00公告会把当天来信全部抹掉。保留的选项使用独立已备货盘、仍实时检查玩家物资，不抢占忙碌、固定事件或觉醒；已展示内容与承诺不变。玩家支援/改托/由他安排继续清空全部未展示计划；旧在途响应因revision递增拒收。npc_action先结算再操作、写日志并保存。时间跨决策/执行边界精确停靠。
- Trade仅创建新报价时采样NPC市场政策；credit_allowed随quote冻结，不能用实时禁止毁掉旧报价。
- 角色面板从「劫余录 → 邻人与商情」进入，纸鹤往来也有入口；显示三人资源、原因、倒计时、对话、行动成本、记录。复用已有HUD入口提示待介入数量，不增加遮挡危机的卡片。
- 归档最终NPC物资、政策和有限已完成行动到Memory，前世只能在真实觉醒后影响NPC，不能当新世惩罚。

## AI 对话范围

复用现有异步导演、请求缓存/节流/失效，low reasoning。当前每人决定作为state.npcs公开上下文；不夹带私有crisis真假或未觉醒前世。plan可选npc_dialogue，仅结构化actor/decision_id/opener/closer目录ID，最多三人；无自由正文、数值、额外奖励。每人10种开场与10种收尾，按本地plain/warm/guarded动机筛选，至少6×6可组合；中间由规则插入真实意图、原因和已觉醒片段。AI只选目录表达不能产生世界事实、改成本、代办危机、许诺新物资。首次展示只冻结表达ID和来源；本地事实段随回应、改托或完成实时更新，不能一直说已经取消的原计划或把已完成行动仍说成未来承诺。迟到响应不能换已经读过的表达。不接收错误ID/重复/额外字段/跨世/已结算响应。离线种子回退不消耗共享RNG，每日局不请求AI，AI开关不改变数值。

已觉醒记忆不等于强制帮忙：生计和相关公开危机优先，然后才考虑信任、未化解失约和记忆回应。每天决定会锁定至执行；中途信任或局势变化参与下一日决定，不重掷当前意图。旧世归档保留最终资源、政策和待执行/已执行状态；日常意图和普通筹措不挤入12条人物关键事实，每个角色仅保留最新有意义自主因果片段。迁居、工棚维修、出城队伍和地图护送尚未开发。
