# 劫余录收拢成三页（2026-10-31）

承接 [37 优化路线图](37-optimization-roadmap.md) 的 B2，也是 [38](38-copy-style.md) 第 5 节遗留的"劫余录最后一个入口被裁掉"的解法。

## 0. 结论

劫余录原来一屏摊开 9 个入口，加目标、要务、人情、日志，一局 20 天每天都要在这一屏里找东西。现在按**为什么打开**分三页：

| 页 | 入口 | 玩家什么时候翻 |
|---|---|---|
| 今世 | 尸劫来历 · 风声与危机 · 这一世的开局 | 「我现在该干什么」 |
| 人 | 邻里事务 · 纸鹤往来 · 邻人与商情 | 「人和事怎么样」 |
| 前世 | 身份与前世 · 轮回调查 · 前世记忆 | 「以前发生过什么」 |

第一日打开只看见今世页的 3 个入口，符合路线图"第 1 日可见入口 ≤ 3 个"。

## 1. 为什么按动机分，不按系统分

原来那 9 个入口是按**做系统的时间顺序**排的：开局 → 主线 → 身份 → 轮回 → 记忆 → 邻里 → 交易 → 邻人 → 危机。这个顺序对开发者有意义（一个系统一批提交），对玩家没有意义——玩家不知道"身份与前世"和"轮回调查"有什么区别，只知道"我要找点事做"。

三页正好对应三种动机，而且和 `Brief`（今日要务）的分工是：Brief 回答"现在干什么"，劫余录三页回答"除此之外还有什么"。

## 2. 与路线图的一处偏离

路线图的分组写的是"前世：开局、身份、轮回、记忆"。我把**开局**放到了今世页，改名为「这一世的开局 · 行囊、人情与风声」。

理由：

- 它讲的就是这一世开局花了什么、和谁打了招呼，放进"前世"页会让玩家以为那是上一世的事；
- 放今世页后，今世页正好 3 个入口，第一日打开就是 3 个，不多不少。

## 3. 放弃了"未触发就不显示入口"

路线图 B2 还写了"还没触发的系统不显示入口"。我先按这个做了，四个判定函数都写好了（危机看有没有风声、纸鹤看有没有交易记录、邻人看有没有自主行动、前世看生死簿世数），然后逐个打开这些面板核对——**没有一个是空壳**：

| 面板 | 没触发时点进去看到什么 |
|---|---|
| 风声与危机 | 「近日没有风声。有新的风声，会挂在宅院上方。」 |
| 纸鹤往来 | 规则说明 + 三个人的报价 |
| 邻人与商情 | 规则说明 + 对方库存 |
| 轮回调查 | 「还没有能查的」 |
| 前世记忆 | 「已记下 0 世」 |

隐藏它们等于让玩家不知道这些系统存在，而且逼得 6 个界面测试必须先造状态才能点入口。分页本身已经把单屏入口从 9 降到 3，认知负担的问题解决了；再藏一遍是矫枉过正。

所以：**只分页，不隐藏**。这条与路线图不一致，记录在此。

## 4. 实现要点

### 4.1 切页不重建弹窗

三页在打开时全部构建好，切换只改 `visible`。重建 modal 会丢掉滚动位置、闪一下、还多一声开合音。

页签是 `UI.button` / `UI.seal_button`（选中态），带 `journal_tab` meta 供测试定位。每次重新打开都从「今世」翻起。

### 4.2 面板高度跟着当前页走

分页以后「人」「前世」页只有三个按钮，如果沿用今世页的高度，下面会留 400px 空白（截图里很难看）。`_fit_journal_height()` 在打开和切页后按内容最小高度重算，封顶 480px；今世页内容多，照旧滚动。

### 4.3 一个真实的死锁：别在隐藏的滚动区上改滚动位置

原来今世页底部的日志区用这个让"打开就看到最新"：

```gdscript
var bar := s.get_v_scroll_bar()
bar.changed.connect(func(): s.scroll_vertical = int(bar.max_value))
```

单页时没问题。分页以后切到别的页会把这一页 `visible = false`，滚动区被隐藏时布局重算会再次触发 `changed`，回调又把滚动位置改回去，**主线程锁在布局里再也不回来**——`npc_ui` 直接卡到 90 秒超时退出，日志一行都不打。

改成打开后 `call_deferred` 落一次底，且只在页面确实可见时做，不跟随时更新。诊断过程记一笔：加三行 `print` 定位到卡在第一个 `snapshot()`，再把滚动逻辑整段去掉验证，才确认是它。

## 6. 未验收范围

- **真人试玩**：没有。入口从 9 个变 3 个是否真的让玩家更快找到东西，只有玩家能回答。
- **页签是否被理解**：「今世 / 人 / 前世」这三个词对没读过文档的玩家是否清楚，未验证。备选是「现在 / 人 / 以前」。
- **第 10 日以后**：只截了第 1 日的三页。那时候今世页的要务更多、人页多了交易记录，未截图。
- `npc_ui` 出现过两次"卡到 90 秒超时"（重跑即过），查到的直接原因是滚动死锁，修掉后 3 次重跑都通过；但不能排除窗口渲染另有一处偶发问题。
