# 第五轮文案：去 AI 味与腔调统一（对照表）

本轮只动两处：`data/npc_dialogue.json` 的 60 条 `text`、`data/omens.json` 的 6 条 `verse`。键名、结构、`tone`、`tier`/`cost`/`effect`/`desc` 一律未动；动机句（`npc_autonomy.gd` 生成的那句）一个字没碰。

## 〇、这一轮改写的两条口径

**口径一：每句要落在一件东西上。** 药罐、竹篮、水缸、米缸、刨花、锯末、铁钉、尺码、鞋、包袱、门槛、檐下、破庙——读的人得能指出来说的是什么。

**口径二：三段要连得上。** `npc_dialogue.gd:114` 的 `_text()` 把三段拼成一个气泡：

```
开场白        ← 本轮的 openers
我的打算：…   ← npc_autonomy.gd 生成，不许动
缘由：…       ← 同上
结束语        ← 本轮的 closers
```

所以开场白是**起头**（把人叫住、把话头递出去），结束语是**收尾**（对刚才那件正事表个态、把决定权交回去）。上一版的开场白都是能独立成句的格言，接不上中间那句，这是读起来假的主因之一。

三条连读样例（前后各是我写的，中间是脚本生成的）：

| 谁 | 玩家实际读到的 |
|---|---|
| 阿宁 | 水缸结了冰，我把要紧的先说。／我的打算：筹措周转。缘由：日子照常过，谈好的报价、欠账和回礼都不变。／话我说到这儿，你看这个价成不成。 |
| 老周 | 你那门框我量过，有事说事。／我的打算：收紧往来。缘由：他收紧了往来：往后的报价多收米 1，也不赊欠。／你说个数，我这边先把料备齐。 |
| 过路客 | 鞋上的雪还没化，我先说事。／我的打算：筹措周转。缘由：日子照常过，谈好的报价、欠账和回礼都不变。／合不合意，你给句话，我好趁天亮上路。 |
