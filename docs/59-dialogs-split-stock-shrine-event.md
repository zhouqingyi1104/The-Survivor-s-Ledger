## 1. 这次要保留哪个"后门"

搬之前先 grep 了要动的符号，找到三处**外部直接调用**，都不能断：

| 调用方 | 调什么 | 处理 |
|---|---|---|
| `scripts/ui/screens/post_screen.gd:1379/1384/1386` | `Dialogs._use("water")` 等速饮速食 | 留 `_use` 转发 |
| `tests/inventory_ui.gd:296` | `Dialogs._item_card({...}, id)` 造格子 | 留 `_item_card` 转发 |
| `tests/offline_events_ui.gd:61` | `Dialogs._event_req_text(...)` 核"几两几文" | 留静态转发 |

**测试没有改**。改测试等于把回归网自己也动了，这批要证明的恰恰是"外面看没变化"，所以宁可多留三个一行的转发。

存货还有一处状态要处理：分类页签原来存在 Dialogs 实例的 `_inventory_filter` 上。搬到模块后改成 `static var _filter`——**和原来等价**，因为 Dialogs 是自动加载单例，本来就是整个进程一份。另外 `get_viewport()` 改成 `UI.host.get_viewport()`（弹窗的宿主就是 main，一行之差）。

## 2. 控件树对照：这次多一条规矩

方法和 [58](58-dialogs-split-house.md) 一样：固定 `--demo` 状态 → 逐节点导出 `类名 | 文本 | disabled | 可见性 | 尺寸` → 前后逐行 diff。但**神龛第一次对照就报了 2 处差异**：

```
< 耳聪目明 「听于无声，视于无形。」 今日外出阳气外泄 -40%。
> 闲云野鹤 「心闲身自在。」 精力 +30。
```

差异不在结构，在**抽到哪三支签**——签是每日随机抽的，两个进程的种子不同。这不是回归，但会让这台对照工具从此不可信（真假差异混在一起）。处理办法：探针里在 `Demo.setup("omens")` 之后把 `run.omens.offer` 固定成 `["wugu", "zhishui", "ercong"]`、清空 `taken` 与 `locked`，再关掉弹窗重开一次，然后**先连跑两遍确认可重复**，才拿去当基线。

结论：**凡是对照的面板里带随机内容（抽签、事件、掉落、天气），必须先把随机源钉死再比**，否则得到的差异无法归因。

最终：

| 面板 | 拆分前 | 拆分后 |
|---|---|---|
| 存货 `inventory` | 157 行 | **完全相同** |
| 神龛求签 `omens` | 51 行（固定三签后） | **完全相同** |
| 事件卡 `event` | 16 行 | **完全相同** |

顺带一句：`event` 只有 16 行是因为 `--demo=event` 摆的是"单选项事件"，面板本来就不长；行数少不等于覆盖小，选项的禁用条件（`Events.choice_block`）在 `offline_events_ui` 的 1292 项里另有覆盖。

## 3. 搬动是否等于行为不变：三条独立证据

1. **控件树逐行相同**（含尺寸、禁用态），说明版面与可点性没动；
2. **`inventory_ui` 397 项**在真实窗口里点着存货格吃喝用药，全过；
3. **`offline_events_ui` 1292 项**逐条走事件选项与"几两几文"的写法，全过。

加上 `check_scripts`（98 个脚本，把新模块也编了一遍）和 `ui_smoke`（整条宅院流程），这批的验证面比第一批更宽——因为存货和事件是玩家每天都会碰到的两个面板。
