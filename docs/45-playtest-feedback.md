状态：**游戏内三问与四处入口已实现，本地定向验证 PASS；真人整局 NOT RUN。** 本文先作为开发前方案写入，随后按实际结果更新。

## 玩家得到什么

已有报告只在 Markdown 末尾留三个空行，玩家需要找到文件再编辑。本批把相同三问接到游戏内：标题、死亡、结局的“导出试玩报告”打开可选填写；游玩中的设置增加同一入口，方便记录第十日等时刻的卡点。设置回标题原本也能导出，本批减少绕行，不声称原来无法反馈。

填写后导出本地报告，空答也能直接导出；取消不导出。保留原有报告事实区和同一时刻的存档附件，不增加后台收集或自动发送。完成后从干净提交刷新离线试玩包，方便实际试玩。

## 本批合同

1. 沿用 `PlaytestReport.QUESTIONS` 的三问，不新增量表或问卷系统。四处入口复用一个表单；只有点击导出才创建文件。
2. 中文、多行、Markdown 标点按玩家原文记录在“玩家自述”区域，不混入客观事实。空答明确为未填写，不推断玩家感受。
3. 每题最多 4000 字；超出时明确提示并保留输入，不静默截断。返回错误时可改写或重试；重复点击不能生成两份同次导出。
4. 表单打开期间保留正在编辑的内容，避免界面刷新清空。取消后不保存草稿、不跨局带入，不增加存档字段、不改原局和底稿。
5. 导出失败保留表单输入；成功才收起表单并显示文件夹与文件清单。继续复用现有独占目录和当前/磁盘快照来源规则。
