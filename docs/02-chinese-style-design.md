# 《劫余录》中国风设计文档

> 定位：参考《生存日志》的"灾前囤货 + 灾后经营 + 轮回"结构，换成**古风尸变 + 写实灾荒 + 少量东方仙侠**。
> 玩法结构可以借鉴；文本、数值、美术全部原创，不搬运原作内容。

## 1. 世界观

**大胤景和十三年冬，江南临川县。**

- **写实的一面（灾荒）**：北方兵败，溃兵南下；秋粮歉收，米价一天三涨；城里先闹"尸瘟"，染病的人高烧咳血。
- **志怪的一面（尸变）**：尸瘟死者停尸三日就会尸变。僵尸怕光、怕火、怕糯米和桃木，**循着活人的阳气找人**，夜里成群出来，这就是"尸潮"。
- **仙侠的一面（轮回与真相）**：主角本该死在尸劫第一夜。阴司判官勾错了名字，留给他一张**生死簿残页**。残页可以"翻回去"，代价是折损寿元。主角每一轮都会多知道一点真相：城外义庄有人在**炼尸**。

**标题：《劫余录》**（劫后余生的记录）。玩家写下的每一天，就是这本录里的一页。

## 3. 核心循环（原型范围）

```
标题 →（心法：用道心学永久能力）→ 选身份
  → 【备劫·三日】城中采购：走动耗时辰，独轮车有负重上限，宵禁前得回家卸货
  → 【尸劫降临】
  → 【劫中·每日】
       晨：神龛求签（花功德）、当日心愿、随机事件
       晨 / 午 / 暮 三个时段，每个时段做一件事：
           外出搜寻 · 生火做饭 · 打理菜畦 · 营造守具 · 修缮门窗 · 读书 · 休养
       不占时段：吃喝用药、去井边打水（每天一次）
       夜：有尸潮就结算防守，没有就睡觉恢复；冷夜要烧炭
       功过格：结算当日功德
  → 气血归零 → 【生死簿】翻回昨日 / 翻回扉页 / 合上
  → 熬过第 20 日 → 【劫满】结局三选：守宅 / 再入轮回 / 合上此录
```

## 4. 关键数值（已用机器人策略调过一轮，可在 `data/*.json` 和 `scripts/core/*.gd` 顶部常量里改）

- **时间（v0.3 起是连续时间）**：一天从卯时 6:00 到次日 6:00。8:00 可能来事件，18:00 天黑，20:00 自动烧炭（1 筐炭或 2 捆柴）取暖，21:00 外出必须回家、尸潮夜要**布防**，22:00 尸潮，23:00 溃兵，6:00 天亮结算功过格。界面流速：正常 4 分钟/秒，快 10，极快 24；忙碌时至少 40，睡觉 150。
- **行动耗时**：做饭 60 分钟，打理菜畦 45，营造 90，修缮 60，读书 120，画符 60，小憩 120，打水 15，赶路单程 60，翻找一处 20。
- **属性衰减（每小时）**：饱腹 −2，饮水 −2.2，心神 −0.5，精力 −1.2（醒着）；睡着时饱腹饮水 ×0.6、精力 +7、气血 +0.8；小憩精力 +10。
- **饿 / 渴 / 病 / 冻（每小时）**：饱腹为 0 气血 −2，饮水为 0 气血 −2.5，尸瘟 −1，体温低于 30 气血 −0.7。夜里没生火，体温每小时掉"寒气 / 10"。
- **井水**：每天打一次，2 瓢（有水缸 +1）；冬至以后井口结冰，少 1 瓢。
- **饭菜**：一锅出 2–4 份。一斗米大约够吃一天，二十天光靠米需要二十多斗，所以备劫时必须囤粮，劫中要种菜、外出补给。
- **寒冷（v0.5 重做）**：节气寒气 10 / 20 / 30 / 25。白天靠日头回暖到 60（有地窖 75），夜里只有生火才暖得起来：1 筐炭或 2 捆柴管一夜（+2/小时，上限 100），只有 1 捆柴时只烧半夜（+1/小时，上限 70）。体温 <30 每小时气血 −0.7，<15 每小时 −1.4 且守力 ×0.85。连续不取暖：第 2 夜开始掉血，第 3 夜起每晚固定 −16.8。
- **尸潮日程（v0.6 拆成三轮）**：第 2、5、8、11、14、17、20 夜，分别来 8、14、18（尸海 ×1.5）、24（铜甲）、34（夹击 + 月黑）、46（铜甲）、58（血月 ×1.2 → 实际 70）只。每夜分三轮（22:00 / 22:40 / 23:20，40% / 35% / 25%），每轮再按 门 50% / 窗 25% / 墙 25% 分三路（夹击时 门 30% / 窗 45% / 墙 25%）。提前一天有预兆（有望楼提前两天）。
- **夜战玩法（v0.6）**：21:00 定方针——稳守（自动修）/ 亲战（自动出门）/ 亲自调度；轮间只能做一件事：修缮 / 贴符 / 布守具 / 出门迎战。详见 `docs/06-night-defense-v0.6.md`。
- **防守公式**：三面独立。每面守力 = 该面守具 + 望楼 2 + 夜行 2 + 六丁六甲 4 + 阿黄 3（只守门）+ 贴在该面的符咒 + 亲守该面时的自身武力 ×（0.5 + 精力/200）。体温 <15 再 ×0.85；点灯 ×1.1；月黑无灯 ×0.7。
  每只僵尸耗守力 1（铜甲 ×1.6，血月 ×1.3）。挡不住的每只扣该面耐久 `5 + floor((日−1)/4)`（第 2 夜 5，第 20 夜 9）；该面低于 25% 时有四分之一挤进来，破了有一半进来，此后每轮来敌全进院子，每只扣 5 气血，并可能染上尸毒。
- **功过格**：存活 +5；心神超过 50 的部分每 10 点 +1；心愿 +2；当夜斩尸每 5 只 +1；行善积德按事件计；存量利息 5%（最少 1、最多 10）。
- **道心**（每轮结束时）：活过的天数 ×1 + 守住的尸潮 ×2 + 新得残卷 ×5，劫满再 +10。心法 8–20 道心一个。
- **平衡验证**（`tests/sim_test.gd`，v0.6）：稳守方针 12 局劫满 8 局，平均存活 19.7 日；方针对照 6 局——稳守 5/6、亲战 5/6、亲自调度但完全不动手 4/6（终局气血 63 / 67 / 34）；偷懒策略 4 局全死在第 9–11 日。第 20 夜的胜负线是三面分别过 19 / 10 / 10，不是总守力。真人试玩后还要再调。

## 6. 迭代路线

1. **原型 v0.1**：Godot 4.7，2D 界面，跑通完整闭环，配置全部用 JSON 表
2. **原型 v0.2**：三个 3D 场景——临川城（点铺子走过去）、宅院（WASD 走动 + E 交互，存货 / 守具 / 菜苗 / 门窗破损都画在场景里）、废墟（提灯翻找）；入夜尸潮演出
3. **原型 v0.3**：参考原版的界面与交互重做——连续时间 + 时辰表盘 + 倍速；深色 HUD（菜畦清单、今夜预警、印章按钮、状态条、常用行为、心愿）；鼠标悬停描边、点击弹动作菜单、寻路走过去做；场景头顶标签；可动关节的人物；瓦垄、程序纹理、院中陈设
4. **原型 v0.4**：接入公开美术资源（Poly Haven 家具贴图、cs-studio 铺面、Quaternius 骨骼人物与动画）；劫中弹窗换成和 HUD 一致的夜色；旧存档自动升级；天光随钟点连续变化
5. **原型 v0.5**：玩法完善——体温变成真约束（白天回暖封顶、一捆柴只烧半夜、冻僵降守力）；漏怪伤害随日子递增；补齐中后期可重复事件；求签同日递增；木料断供可用柴顶替
6. **原型 v0.6（当前）**：夜战三式——门 / 窗 / 院墙三面独立耐久与守力、一夜三轮、轮间两个间隙只够做一件事（修缮 / 贴符 / 布守具 / 出门迎战）；守夜方针三档（稳守 / 亲战 / 亲自调度），生活玩家和战斗玩家各走各的路
7. 接下来：轮间的小演出、出门迎战做成实地操作、僵尸分路行走、守具可拆下重挂；多层宅院（阁楼 / 地窖）
8. 纸鹤交易、邻家小妹线、机关傀儡、节气天气
9. 残卷真相线和多结局，无尽模式；Steam 发布
